# Team-AND

로봇 손(Hiwonder uHand)과 웹캠을 연결해, 사람의 손동작을 인식하고 로봇 손이 따라 움직이도록 만드는 팀 프로젝트예요.

## 폴더 구조

```
Team-AND/
├── README.md          # 큰 주제 (이 파일)
├── 공용폴더/          # 팀 공용 코드·자료
│   ├── P1/
│   ├── P2/
│   └── ...
└── 개인폴더/          # 각자 이름(또는 이메일) 폴더
    ├── 김다혜/
    │   ├── P1/        # 웹캠 손 추적 → uHand 제어
    │   ├── P2/
    │   └── ...
    └── (팀원 이름)/
        ├── P1/
        └── ...
```

## 올리는 규칙
- 팀 전체가 같이 쓰는 코드·자료는 `공용폴더/P번호/`에 올려요.
- 개인 작업은 `개인폴더/본인이름/P번호/`에 올려요.
- 각 P 폴더에는 실행 방법을 적은 `README.md`를 같이 넣어 주세요.

## 진행 현황
| 위치 | 내용 |
|---|---|
| `개인폴더/김다혜/P1` | 웹캠(MediaPipe)으로 손 인식 → micro:bit → uHand 서보 제어 |
| `개인폴더/김다혜/P2` | 손목 카메라(WonderCam) 특징 학습 → 손 모양(✊✋✌️) 따라 하기 (micro:bit 단독) |
| `개인폴더/김다혜/P3` | **최종 통합**: 김윤하 P5에 손목 카메라 따라 하기 모드(C) 추가 — 카메라를 아래로 두고 손 동작 7가지 인식 |
| `개인폴더/김윤하/P1` | IR 리모컨 → micro:bit(MakeCode) → 서보 제어, 리모컨/비전 모드 전환 + PC 상태 보고 |
| `개인폴더/김윤하/P2` | 웹 제어(카메라 영상 + 슬라이더 조종 + 카메라 켜기/끄기), 리모컨·웹 동시 조종, 통신 안정화 |
| `개인폴더/김윤하/P3` | 움직이기 전 0.5초 알림음 → 그다음 움직임 (micro:bit 내장 스피커, 로고 터치로 켜기/끄기) |
| `개인폴더/김윤하/P4` | ESP32-S3(XIAO Sense) 손 카메라 → 와이파이 영상, 웹 카메라 선택(웹캠 / 손 카메라) |
| `개인폴더/김윤하/P5` | **최종**: 웹캠 CCTV 보기 + 웹·리모컨 조종 + 웹캠 손 따라 하기(버튼/EQ) + 움직이기 전 0.5초 알림음 + micro:bit 2개 무선 연결 |
