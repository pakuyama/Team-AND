# Team-AND · 움직이기 전 알림음 (김윤하 P3)

로봇 손이 **움직이기 전에 micro:bit에서 0.5초 소리가 나고, 소리가 끝나면 움직여요.** [P2](../P2)의 리모컨 + 웹 통합 허브에 이 기능만 더한 버전이에요.

## 폴더 구조

```
microbit/
  microbit_ir_hub.ts   # micro:bit 코드 (MakeCode JavaScript). P2 버전을 대체해요
```

웹 서버(`web_server.py`, `index.html`, `run_web.bat`)는 바뀐 게 없어서 [P2/web](../P2/web)을 그대로 써요.

## 실행 방법
1. [makecode.microbit.org](https://makecode.microbit.org) 에서 새 프로젝트를 만들어요.
2. **확장 프로그램**에 아래 주소를 넣고 `MakerBit-IR-Receiver`를 추가해요.
   ```
   https://github.com/1010Technologies/pxt-makerbit-ir-receiver
   ```
3. **JavaScript** 탭에 `microbit/microbit_ir_hub.ts` 내용을 붙여넣고 다운로드해요.
4. 웹 조종은 [P2 README](../P2/README.md#실행-방법)대로 웹 서버를 실행해요.

배선과 리모컨 버튼은 [P1 README](../P1/README.md)와 같아요.

## 움직이기 전 알림음
소리는 **micro:bit V2의 내장 스피커**에서 나요. 부품을 더 달 필요는 없어요.

| 상황 | 소리 |
|---|---|
| 멈춰 있다가 리모컨 · 웹 · A/B 버튼으로 움직일 때 | "삐—" 0.5초 → 소리가 끝나면 움직임 |
| 계속 움직일 때 (리모컨 +/-를 누르고 있거나 웹 슬라이더를 끌 때) | 처음 한 번만 소리. 0.8초 넘게 멈춰 있어야 다시 소리가 나요 (매번 0.5초씩 기다리면 너무 느려서) |
| 숫자 세기 동작 | 시작할 때 한 번 |
| 비전 모드(`P`) | 소리가 나지 않아요 (명령이 계속 들어와서) |
| **micro:bit 로고(금색 부분) 터치** | 소리 켜기("삐삐") / 끄기(낮은 "뿌") |

- 소리가 나는 동안 리모컨이나 웹으로 값을 더 바꾸면, 소리가 끝난 뒤 **마지막 값으로** 움직여요.
- 코드 위쪽 숫자로 조절해요: `BEEP_MS` 소리 길이(기본 500ms), `BEEP_GAP` 다시 소리 나기까지 멈춰 있어야 하는 시간(기본 800ms, 0이면 매번 소리), `BEEP_FREQ` 음 높이(기본 880Hz).
- 통신 규칙은 [P2](../P2/README.md#통신-규칙-usb-시리얼-115200bps--p1에서-바뀐-점-)와 같아요.

## 오늘 한 일 (P2 + P3)
1. **웹 제어** (P2): 브라우저에서 카메라 영상을 보면서 슬라이더와 동작 버튼으로 손을 조종하고, 카메라를 켜고 끌 수 있어요.
2. **리모컨 + 웹 동시 조종** (P2): 수동 모드에서는 둘 다 쓸 수 있고, 마지막 명령이 적용돼요.
3. **통신 안정화** (P2): 시리얼 버퍼를 늘리고, 합계로 깨진 줄을 걸러내고, 적용이 안 된 명령은 다시 보내요.
4. **WonderCam 조사** (P2): 영상은 밖으로 보낼 수 없고 인식 결과만 받을 수 있어서, 웹 영상은 USB 웹캠을 써요.
5. **움직이기 전 알림음** (P3): 0.5초 소리가 난 뒤 움직이고, 로고를 터치하면 켜고 꺼요.
