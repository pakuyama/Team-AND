# Team-AND · IR 리모컨으로 로봇 손 제어 (김윤하 P1)

IR 적외선 리모컨으로 Hiwonder AiHand 로봇 손을 조종해요. 리모컨 수신과 PC(비전·웹 모니터링) 연결을 micro:bit 하나가 함께 처리해요.

```
IR 리모컨 ─▶ IR 수신 센서 ─(P1)─▶ micro:bit ─(P12 시리얼)─▶ 확장보드 ─▶ 서보 6개
                                     ▲  │
                     PC 비전 명령 ───┘  └──▶ 상태 보고 (웹 모니터링용)
```

## 파일

| 파일 | 설명 |
|---|---|
| `microbit_ir_hub.ts` | micro:bit에 넣는 메인 코드 (MakeCode JavaScript) |
| `port_finder.ts` | IR 센서가 어느 핀에 연결됐는지 확인하는 테스트 코드 |

## 배선

확장보드의 **5V · GND · P1 · P2** 라고 적힌 4핀 포트에 연결해요.

| 포트 칸 | IR 센서 |
|---|---|
| 5V | VCC (+) |
| GND | GND (−) |
| P1 | OUT (S) — **중간에 10kΩ 저항** (5V 출력으로부터 micro:bit 보호) |
| P2 | 연결 안 함 |

전원 스위치를 끈 상태에서 연결하고, 센서의 VCC/GND가 바뀌지 않았는지 꼭 확인하세요.

## 실행 방법

1. [makecode.microbit.org](https://makecode.microbit.org) 에서 새 프로젝트를 만들어요.
2. **확장 프로그램**에 아래 주소를 붙여넣고 `MakerBit-IR-Receiver`를 추가해요. (StartbitV2 확장은 넣지 않아요)
   ```
   https://github.com/1010Technologies/pxt-makerbit-ir-receiver
   ```
3. **JavaScript** 탭에 `microbit_ir_hub.ts` 내용을 붙여넣고 다운로드해요.
4. LED에 `R`이 보이면 리모컨 모드예요. micro:bit **A 버튼 = 펴기, B 버튼 = 주먹**으로 서보 동작을 먼저 확인하세요.

리모컨에 반응이 없으면 `port_finder.ts`를 넣고 리모컨을 눌러 LED에 `1`이 나오는지 확인하세요. 버튼 코드가 다르면 USB 시리얼 창에 나오는 `# IR 0x..` 값으로 코드 위쪽의 버튼 코드표를 바꾸면 돼요.

## 리모컨 버튼 (21키 리모컨 기준)

| 버튼 | 기능 |
|---|---|
| 1~5 / 6 / CH | 손가락 선택 (엄지~새끼) / 회전대 선택 / 손가락 전체 |
| + / − | 선택한 것 펴기 / 접기 (누르고 있으면 계속) |
| \|<< / >>\| | 회전대 왼쪽 / 오른쪽 |
| CH− / CH+ | 움직이는 간격 5 / 10 / 20도 |
| >\|\| | 펴기 ↔ 주먹 |
| 0 | 중립 (모두 90도) |
| 7 / 8 / 9 / 200+ | 가위 / 바위 / 보 / 좋아요 |
| 100+ | 숫자 세기 동작 |
| **EQ** | **리모컨 모드 ↔ 비전 모드 전환** |

비전 모드에서 EQ 외의 버튼을 누르면 바로 리모컨 모드로 돌아와요 (비상 정지 역할).

## 팀원 연동 (USB 시리얼 115200bps)

| 방향 | 메시지 | 의미 |
|---|---|---|
| PC → micro:bit | `S,a1,a2,a3,a4,a5,a6,dur` | 서보 6개 각도(0~180)와 이동 시간(ms). **비전 모드일 때만 적용** |
| PC → micro:bit | `PING` | `READY` 응답 |
| micro:bit → PC | `A,<모드>,a1,...,a6` | 현재 상태. 모드 `R`=리모컨, `P`=비전 (웹 모니터링용) |
| micro:bit → PC | `R` | 지금 명령을 보내도 됨 (받으면 바로 `S,...` 전송) |
| micro:bit → PC | `K` | PC 명령 적용 완료 |

서보 번호: 1 엄지, 2 검지, 3 중지, 4 약지, 5 새끼, 6 회전대.
USB 포트는 한 프로그램만 열 수 있으니, 비전 프로그램이 포트를 열고 상태를 웹 쪽에 넘겨주는 구조를 권장해요.

## 참고
- 실제 하드웨어 테스트 전이에요. 서보 방향이나 각도 범위가 다르면 코드 위쪽 `OPEN_A`, `CLOSE_A` 값을 조정하세요.
- 서보 명령 형식은 Hiwonder 공식 StartbitV2 확장과 같아요.
