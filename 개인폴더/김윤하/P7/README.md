# AiHand 최종 프로젝트 실제 구현 (김윤하 P7)

[P6](../P6)에 있는 코드를 **micro:bit 2개로 실제로 구현**했어요.
구현하면서 **웹 연결이 끊겼다가 다시 연결되기를 반복하는 현상**을 발견해서 고쳤어요.

```
PC (web_server.py) ─USB─ micro:bit ① pc_bridge  ~~ 무선 ~~  micro:bit ② robot_hub ─ 확장보드 ─ 서보 6개
                                                                         └ 전원 선
```
P6 때는 micro:bit가 1개라서 연결선이 2개였어요. 이제는 로봇 손 쪽에 **전원 선 하나만** 남아요.

## 실제 구현 순서
1. ② 로봇 손 micro:bit에 `microbit/robot_hub.ts`를 넣고 확장보드에 꽂아요 (IR 수신 확장 필요).
2. ① PC 쪽 micro:bit에 `microbit/pc_bridge.ts`를 넣고 PC USB에 꽂아요. 화면에 ✓가 뜨면 무선 연결 성공이에요.
3. `web/run_web.bat`을 실행하고 http://localhost:8000 에서 조종하거나 **✋ 따라 하기**를 눌러요.

## 발견한 문제: 웹 연결이 끊겼다 연결됐다 반복
**현상**
- 웹 화면의 micro:bit 연결 표시가 계속 "연결됨"과 "끊김"을 오갔어요.
- 그래서 따라 하기 모드가 제대로 켜지지 않았어요.

**원인**
- ② → ① 무선 신호는 0.1초마다 잘 오고 있었어요. 문제는 ① → PC USB 구간이었어요.
- ①이 USB로 보내는 글자 중 일부가 빠졌어요.
  ```
  보낸 줄:  A,R,130,50,50,50,50,90,420
  받은 줄:  A,R,13,50,5050,5,90,420      ← 글자가 빠짐
  ```
- 서버는 각도 합계가 안 맞는 줄을 버리는데, 버려지는 줄이 절반쯤 됐어요.
- 2초 동안 온전한 줄이 하나도 안 오는 순간이 생기면 서버가 "끊김"으로 판단했어요.

**수정** (`web/web_server.py`)
| | P6 | P7 |
|---|---|---|
| 연결 판단 | 합계가 맞는 상태 줄을 2초 안에 받았는지 | **어떤 글자든** 2초 안에 받았는지 |
| 모드(R/P) | 합계가 맞는 줄에서만 읽음 | 줄 맨 앞 `A,R,` / `A,P,`에서 읽음 (뒤쪽이 깨져도 반영) |
| 각도 | 합계가 맞는 줄만 사용 | 그대로 (정확해야 하니까) |

micro:bit 코드는 바꾸지 않았어요. 서버만 고치면 돼요.

**결과**
- 연결 상태를 연속으로 확인했을 때 계속 "연결됨"이었어요.
- 따라 하기 모드 켜기/끄기도 잘 됐어요.

## 폴더 구조
```
microbit/
  robot_hub.ts    # ② 로봇 손 micro:bit (P6와 같음)
  pc_bridge.ts    # ① PC 쪽 micro:bit (P6와 같음)
web/
  web_server.py   # 연결 끊김 수정
  index.html      # P6와 같음
  run_web.bat
```
