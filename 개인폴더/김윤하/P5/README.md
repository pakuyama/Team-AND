# AiHand 최종 프로젝트 (김윤하 P5)

PC 웹캠으로 로봇 손을 **CCTV처럼 보고**, **웹이나 리모컨으로 조종**하고, 버튼 하나로 **내 손을 따라 하게** 합니다.
로봇 손은 움직이기 전에 **0.5초 알림음**을 냅니다. micro:bit 2개를 **무선**으로 연결해서 PC와 로봇 손 사이에 선이 없습니다.

```
                 웹 브라우저 (영상 보기 · 조종 · 손 인식)
                        │
PC 웹캠 ─▶ PC (web_server.py) ─USB─ micro:bit ① pc_bridge
                                          ~~~ 무선 (radio) ~~~
            IR 리모컨 ─▶ micro:bit ② robot_hub ─▶ 확장보드 ─▶ 서보 6개
                                     (알림음 0.5초)
```

## 최종 목표와 구현
| 목표 | 구현 |
|---|---|
| 카메라로 CCTV처럼 보기 | PC 웹캠 영상을 웹 화면에 표시 (지금 시각 표시, 같은 와이파이 휴대폰에서도 보기) |
| 웹·리모컨 버튼으로 따라 하기 | 웹 **✋ 따라 하기** 버튼 / 리모컨 **EQ** (다시 누르거나 다른 버튼을 누르면 수동 조종) |
| 움직이기 전 0.5초 소리 | micro:bit V2 내장 스피커. 소리가 끝나면 움직임 (로고 터치로 켜기/끄기) |
| 웹캠으로 손 인식해서 따라 하기 | 웹 화면(브라우저)에서 MediaPipe로 손 인식 → 손가락 각도 → 로봇 손 |
| micro:bit 2개 무선 연결 | micro:bit radio. PC 쪽 ①이 PC 명령을 무선으로 로봇 쪽 ②에 전달 |

## 폴더 구조
```
microbit/
  robot_hub.ts    # ② 로봇 손 micro:bit: 리모컨, 서보, 알림음, 무선 받기 (MakeCode)
  pc_bridge.ts    # ① PC micro:bit: USB ↔ 무선 중계 (MakeCode)
web/
  web_server.py   # 웹캠 영상 + 조종 + 따라 하기 명령 전달
  index.html      # 웹 화면 (손 인식 포함)
  run_web.bat     # 더블클릭으로 실행
```

## 1. micro:bit 2개 준비 ([MakeCode](https://makecode.microbit.org))
**② 로봇 손 micro:bit (`robot_hub.ts`)**
1. 새 프로젝트 → 확장에서 `https://github.com/1010Technologies/pxt-makerbit-ir-receiver` 추가
2. JavaScript 탭에 `robot_hub.ts` 전체를 붙여넣고 다운로드
3. 확장보드에 꽂습니다. IR 수신 센서: OUT → P1, VCC → 3V, GND → GND

**① PC micro:bit (`pc_bridge.ts`)**
1. 새 프로젝트 (확장 필요 없음) → JavaScript 탭에 `pc_bridge.ts` 전체를 붙여넣고 다운로드
2. PC USB에 꽂아 둡니다. 로봇 신호가 오면 화면에 ✓, 안 오면 ✗가 표시됩니다.

> - 두 파일의 `RADIO_GROUP` 번호가 같아야 합니다. 다른 팀과 겹치면 둘 다 같은 번호로 바꾸세요.
> - **Bluetooth 확장은 넣지 마세요.** micro:bit끼리 무선(radio)과 Bluetooth는 같이 쓸 수 없습니다.
> - 로봇 쪽 ②는 확장보드 전원으로 켭니다. ②를 PC USB에 같이 꽂으면 웹 서버가 ①과 헷갈릴 수 있습니다.
> - 무선 거리: 실내 약 10~20m입니다.
> - 무선 없이 써도 됩니다: ②를 PC USB에 바로 꽂으면 똑같이 동작합니다.

## 2. 웹 서버 실행
```
pip install opencv-python numpy pyserial
```
`web/run_web.bat`을 더블클릭하면 서버가 켜지고 브라우저가 열립니다 (http://localhost:8000).
- 손 인식은 **브라우저 안에서** 합니다 (MediaPipe for Web). 처음 한 번 인터넷에서 불러오므로 인터넷 연결이 필요합니다.
  (이 PC는 보안 정책 때문에 파이썬 MediaPipe가 막혀 있어서 브라우저 방식을 사용했습니다)
- 손 인식 모델(`hand_landmarker.task`)이 없으면 서버가 처음에 자동으로 받습니다.
- 같은 와이파이의 휴대폰에서도 `http://<PC IP>:8000`으로 볼 수 있습니다. 따라 하기는 **한 화면에서만** 켜 두세요.

## 3. 사용 방법
- **수동 조종**: 리모컨 또는 웹 슬라이더·동작 버튼으로 조종합니다. 마지막 명령이 적용됩니다.
- **따라 하기**: 웹 **✋ 따라 하기** 또는 리모컨 **EQ** → 웹캠에 손을 보여 주면 로봇 손이 따라 합니다.
  - 화면에 손 뼈대가 그려지면 인식된 것입니다. 회전대는 그대로 있고 손가락 5개만 따라 합니다.
  - 손가락이 끝까지 안 펴지거나 안 접히면 **편 손 보정** / **주먹 보정** 버튼을 누릅니다 (브라우저에 기억됩니다).
  - 웹이나 리모컨으로 조종하면 바로 수동 조종으로 돌아옵니다.
- **알림음**: 한동안 멈춰 있다가 움직일 때 0.5초 소리가 난 뒤 움직입니다. 계속 움직이는 중에는 소리가 나지 않습니다.

### 리모컨 버튼 (21키 "Car MP3" 리모컨)
| 버튼 | 동작 |
|---|---|
| EQ | 따라 하기 켜기/끄기 |
| 1~5 / 6 / CH | 손가락 선택 / 회전대 선택 / 손가락 전체 |
| + / - | 펴기 / 접기 (회전대는 왼쪽 / 오른쪽, 누르고 있으면 계속) |
| \|<< / >>\| | 회전대 왼쪽 / 오른쪽 |
| CH- / CH+ | 움직임 간격 5 / 10 / 20도 |
| >\|\| | 펴기 ↔ 주먹 |
| 0 / 7 / 8 / 9 | 중립 / 가위 / 바위 / 보 |
| 200+ / 100+ | 좋아요 / 숫자 세기 |

## 무선 통신 규칙 (팀원 공유용)
패킷 첫 바이트는 `0xA5`(우리 팀 표시)이고, 무선 그룹은 `RADIO_GROUP`입니다.
| 방향 | 패킷 | 뜻 |
|---|---|---|
| PC → 로봇 | `A5 'W' a1..a6 시간L 시간H` | 웹 조종 (언제든 적용, 따라 하기 중이면 수동으로) |
| PC → 로봇 | `A5 'S' a1..a6 시간L 시간H` | 따라 하기 (따라 하기 모드일 때만) |
| PC → 로봇 | `A5 'M' 'R'/'P'` | 모드 바꾸기 |
| 로봇 → PC | `A5 'A' 모드 a1..a6` | 상태 (0.1초마다) |
| 로봇 → PC | `A5 'I' 코드` | 눌린 리모컨 버튼 |

PC ↔ ① 사이 USB 글자 규칙은 P2~P4와 같습니다 (`W,…,sum` / `S,…` / `M,R|P` / `A,모드,…,sum` / `R`).
