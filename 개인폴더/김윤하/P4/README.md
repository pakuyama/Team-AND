# Team-AND · 손 카메라 (ESP32-S3) + 웹 카메라 선택 (김윤하 P4)

로봇 손 근처에 **XIAO ESP32S3 Sense** 카메라를 달아서, 손 위치에서 보이는 영상을 웹 제어 화면에서 봅니다.
[P2](../P2)의 웹 제어에 이 기능을 더했고, micro:bit 코드는 [P3](../P3)를 그대로 사용합니다.

> **외부 카메라를 단 이유**
> 현재 로봇 손에 달려 있는 카메라(WonderCam)는 영상을 웹으로 보낼 수 없습니다. 손 모양 같은 **인식 결과만** I2C로 보내고, 영상은 밖으로 내보내지 않습니다 (Hiwonder 공식 문서 기준).
> 그래서 영상을 보낼 수 있는 **외부 카메라(XIAO ESP32S3 Sense)를 따로 달아서** 손 위치에서 보이는 영상을 웹에 띄웁니다.

```
XIAO ESP32S3 Sense ──와이파이──▶ 웹 브라우저 (✋ 손 카메라 영상)
                                     │ 조종
IR 리모컨 ─▶ micro:bit ◀─USB─▶ PC (web_server.py) ◀┘
                │
           확장보드 ─▶ 서보 6개
```

## 폴더 구조

```
esp32/
  esp32s3_cam/esp32s3_cam.ino   # ESP32-S3 카메라 → 와이파이 MJPEG 영상 (Arduino)
web/
  web_server.py                 # P2 + 카메라 주소(URL) 지원
  index.html                    # P2 + 카메라 선택 (💻 웹캠 / ✋ 손 카메라)
  run_web.bat                   # 웹캠으로 실행 (더블클릭)
  run_web_handcam.bat           # PC가 손 카메라 영상을 받아서 보내 주는 방식으로 실행
```

## 1. ESP32-S3 카메라 (Arduino IDE)
1. **파일 > 기본 설정 > 추가 보드 관리자 URL**에 아래 주소를 넣습니다.
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
2. 보드 관리자에서 `esp32 by Espressif Systems`를 설치합니다.
3. `esp32s3_cam.ino` 맨 위를 고칩니다.
   - `WIFI_SSID`, `WIFI_PASS`: 와이파이 이름과 비밀번호 (2.4GHz만 됩니다)
   - 보드 종류: 기본값은 `BOARD_XIAO_S3_SENSE`입니다. Freenove나 ESP32-S3-CAM이면 `BOARD_S3_EYE_TYPE`으로 바꿉니다.
4. **도구** 메뉴: 보드 `XIAO_ESP32S3`, PSRAM `OPI PSRAM`, USB CDC On Boot `Enabled`
5. 업로드합니다. 연결이 안 되면 **B(BOOT) 버튼을 누른 채** USB를 꽂고 다시 시도합니다.
   `Hard resetting via RTS pin...`이 나오면 성공입니다. 끝나면 **R(RESET)** 버튼을 누릅니다.
6. 시리얼 모니터(115200)에 `영상 주소: http://192.168.x.x:81/stream`이 나옵니다.

> ⚠️ 와이파이 비밀번호를 넣은 `.ino`는 깃에 올리지 마세요. 이 폴더의 파일은 비워 둔 상태입니다.

**달기**
- 안테나를 꼭 끼웁니다. 회전대 위쪽이나 손목 옆에 고정합니다.
- 전원은 USB-C(PC·충전기·보조배터리)로 주거나, 확장보드 **5V → XIAO `5V`, GND → `GND`**로 줍니다. `3V3` 핀은 사용할 수 없습니다.
- USB 전원과 핀 전원을 동시에 쓰지 마세요.

## 2. 웹에서 손 카메라 보기
1. `run_web.bat`으로 웹 서버를 켜고, 웹 화면에서 **✋ 손 카메라**를 누릅니다.
2. ESP32 주소를 넣고 **적용**을 누릅니다. IP만 넣어도 됩니다. 주소는 브라우저에 기억됩니다.
3. 영상은 **브라우저가 ESP32에서 바로** 받습니다. 그래서 **웹을 보는 기기가 ESP32와 같은 와이파이**에 있어야 합니다.
4. 연결이 안 되면 화면에 확인할 것들이 나오고, 3초마다 다시 시도합니다.
5. 📷 버튼은 지금 고른 카메라를 켜고 끕니다. **💻 웹캠**을 누르면 PC 웹캠으로 돌아갑니다.

PC가 ESP32와 같은 네트워크에 있으면 다른 방식도 쓸 수 있습니다. `run_web_handcam.bat`(`--camera http://…/stream`)으로 켜면 **PC가 영상을 받아서 대신 보내 줍니다.** 이렇게 하면 여러 명이 같이 볼 수 있습니다.

## 네트워크 주의
- `192.168.x.x` 주소는 **같은 공유기(와이파이) 안에서만** 열립니다.
- PC가 공유기를 거치지 않고 인터넷에 바로 연결돼 있으면, PC와 ESP32는 서로 찾을 수 없습니다. 이때는 **PC 랜선을 공유기 LAN 포트에 꽂거나** USB 와이파이 동글로 같은 와이파이에 연결합니다.
- 웹 서버에는 비밀번호가 없습니다. 방화벽에서 **공용 네트워크를 허용하지 마세요.**
- ESP32는 영상을 **한 곳에만** 보낼 수 있습니다. 한 기기에서만 보세요.

## 오늘 한 일 (11/21)
1. **ESP32-S3 카메라 코드**: XIAO ESP32S3 Sense 카메라 영상을 와이파이로 보냅니다. 와이파이가 끊기면 자동으로 다시 연결하고, 카메라나 와이파이가 실패하면 재시작합니다.
2. **XIAO ESP32S3에 업로드에 성공**했고, 영상 주소가 나오는 것까지 확인했습니다.
3. **웹 서버**: `--camera`에 카메라 번호 대신 영상 주소도 넣을 수 있습니다. JPEG를 다시 압축하지 않고 그대로 넘기고, 끊기면 다시 연결합니다.
4. **웹 화면**: 카메라 선택(💻 웹캠 / ✋ 손 카메라), 손 카메라 주소 입력·기억, 연결 실패 안내, 자동 재시도
5. **네트워크 확인**: PC가 공유기 밖에 있어서, ESP32와 같은 네트워크에 연결하는 방법을 정리했습니다.
