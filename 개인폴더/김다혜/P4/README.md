# P4 · XIAO ESP32S3 Sense로 CCTV 만들기 (김다혜)

팀 최종 목표인 **"카메라로 CCTV처럼 보기"**를 XIAO ESP32S3 Sense 하나로 해 본 거예요.
김윤하 [P4](../../김윤하/P4)는 영상을 보내는 데까지(한 곳에만) 했어요. 여기서는 그 위에 **CCTV 기능**을 더했어요.

```
                         ┌─ 폰 브라우저  ┐
XIAO ESP32S3 Sense ─와이파이─┼─ 노트북 브라우저 ├ 최대 3대 동시에 실시간 보기
 (카메라 + microSD)        └─ 팀 웹(P3/P7) ┘
   │ 움직임 감지 → microSD에 자동 녹화 → 웹에서 다시 보기
```

## 김윤하 P4와 다른 점
| | 김윤하 P4 | **김다혜 P4 (CCTV)** |
|---|---|---|
| 실시간 영상 | 한 곳만 볼 수 있음 | **3대까지 동시에** |
| 움직임 감지 | - | **화면이 바뀌면 감지 (민감도·면적 조절)** |
| 녹화 | - | **움직임이 있으면 microSD에 0.5초마다 사진 저장, 사건별 폴더** |
| 다시 보기 | - | **웹에서 사건 목록 → 넘겨 보기 / 재생 / 내려받기 / 지우기** |
| 시계 | - | **화면에 날짜·시간 (인터넷 시간, 없으면 웹을 연 기기 시간)** |
| 스냅샷 | - | **지금 장면 JPG 내려받기** |
| 와이파이 | 코드에 비밀번호 넣고 업로드 | **폰으로 설정 화면에서 저장 (코드에 비밀번호 안 넣음)** |
| 공유기가 없을 때 | 볼 수 없음 | **ESP32가 직접 와이파이를 만들어서 폰으로 바로 볼 수 있음** |
| 설정 | 코드 수정 후 다시 업로드 | **웹에서 해상도·화질·반전 바꾸기 (꺼도 기억)** |
| 공간 관리 | - | **SD 남은 공간이 10%보다 적으면 오래된 사건부터 자동 삭제** |

영상 주소는 김윤하 P4와 똑같이 `http://<IP>:81/stream`이라서, 팀 웹 화면의 "✋ 손 카메라"에 그대로 넣어도 돼요.

## 파일
```
esp32s3_cctv/
  esp32s3_cctv.ino    # ESP32 코드 (카메라, 여러 명 영상, 움직임 감지, 녹화, 웹 API, 와이파이)
  page.h              # CCTV 웹 화면 (ESP32 안에 들어감)
  secrets_example.h   # (선택) 와이파이를 코드에 넣고 싶을 때 secrets.h로 복사해서 사용
  .gitignore          # secrets.h는 깃에 안 올라감
```

## 실제 구현 순서

### 1. 준비물
- XIAO ESP32S3 **Sense** (카메라 보드를 위에 끼운 것), 안테나
- microSD 카드 (32GB 이하, **FAT32**로 포맷) → Sense 보드 옆 슬롯에 꽂기. 없어도 실시간 영상은 돼요.
- USB-C 케이블

### 2. 업로드 (Arduino IDE, 김윤하 P4와 같은 설정)
1. 보드 관리자에 `esp32 by Espressif Systems`가 설치돼 있어야 해요.
   (없으면 기본 설정 > 추가 보드 관리자 URL에 `https://espressif.github.io/arduino-esp32/package_esp32_index.json`)
2. `esp32s3_cctv` 폴더를 통째로 열어요. (`esp32s3_cctv.ino`와 `page.h`가 같은 폴더에 있어야 해요)
3. **도구** 메뉴
   - 보드: `XIAO_ESP32S3`
   - PSRAM: `OPI PSRAM` ← **꼭!** (안 하면 시리얼에 "PSRAM이 없어요"가 나와요)
   - USB CDC On Boot: `Enabled`
4. 업로드. 안 되면 **B(BOOT)를 누른 채** USB를 꽂고 다시. 끝나면 **R(RESET)**.
5. 시리얼 모니터(115200)에 이렇게 나와요.
   ```
   설정 모드 와이파이: AiHand-CCTV-1A2B (비밀번호 aihand1234)
   CCTV 화면:  http://192.168.4.1
   ```

### 3. 와이파이 연결
1. 폰 와이파이에서 **AiHand-CCTV-xxxx**에 연결해요 (비밀번호 `aihand1234`).
2. 폰 브라우저에서 **http://192.168.4.1** → CCTV 화면이 바로 나와요. (이 상태로도 CCTV로 쓸 수 있어요)
3. 맨 아래 **와이파이 설정**에 공유기 이름·비밀번호를 넣고 저장 → 다시 시작해요. (2.4GHz만 돼요)
4. 폰을 다시 공유기 와이파이에 연결하고 **http://aihand-cctv.local** 또는 시리얼 모니터에 나온 `http://192.168.x.x`로 들어가요.
   - 연결에 실패하면 자동으로 다시 AiHand-CCTV-xxxx 모드로 켜져요.
   - 저장한 와이파이 지우기: **BOOT를 누른 채 RESET** → BOOT를 3초 더 누르기

### 4. 사용
- **실시간 영상**: 화면 왼쪽 위에 시간, 움직임이 있으면 왼쪽 아래 빨간 "⚠ 움직임 감지", 녹화 중이면 오른쪽 위 🔴 REC
- **스냅샷**: 📸 버튼 → 지금 장면이 `cctv_날짜_시간.jpg`로 저장돼요
- **녹화된 사건**: 카드를 누르면 사진을 넘겨 보거나 ▶ 재생(0.5초 간격), ⬇ 내려받기, 🗑 지우기
- **설정** (오른쪽): 해상도, 화질, 상하·좌우 반전, 움직임 감지/자동 녹화 켜기·끄기, 민감도, 감지 면적. 바꾸면 바로 적용되고, 꺼도 기억해요.
- **⏸ 영상 멈춤**: 3명이 다 보고 있을 때 자리를 비켜 주는 버튼이에요.

### 5. 달기
- 안테나를 꼭 끼우고, 지켜볼 곳(로봇 손 작업대 등)이 보이게 고정해요.
- 전원은 USB-C(충전기·보조배터리)로 줘요. 확장보드 5V를 쓸 때는 김윤하 P4 README의 전원 주의를 지켜 주세요.

## 동작 방식 (코드 설명)
| 부분 | 하는 일 |
|---|---|
| 카메라 작업 (`cameraTask`) | 사진을 계속 찍어서 "가장 최근 사진" 하나에 넣어 둬요. 0.25초마다 사진을 1/8 크기 흑백으로 줄여서 이전 화면과 비교해요. 밝기가 `민감도`보다 많이 바뀐 점이 화면의 `감지 면적`% 이상이면, 두 번 연속일 때 움직임으로 봐요 (깜빡임 무시). 설정을 바꾼 뒤 3초는 쉬어요 (밝기 자동 조절 때문). |
| 영상 서버 (81번) | 들어온 시청자마다 작업을 하나씩 만들어서, 같은 "가장 최근 사진"을 각자 보내요. 그래서 여러 명이 동시에 볼 수 있어요 (최대 3명, 넘으면 503). |
| 녹화 (`recordStep`) | 움직임이 시작되면 `/cctv/20261128_153012/` 폴더를 만들고 `0000.jpg, 0001.jpg…`를 0.5초마다 저장해요. 움직임이 멈추고 5초 더 찍고 끝나요. 한 사건 최대 240장(2분). |
| 웹 서버 (80번) | 화면(`page.h`)과 API: `/api/status`, `/api/set`, `/api/events`, `/api/event`, `/sd`, `/capture`, `/api/time`, `/api/wifi` |
| 와이파이 | 저장한 공유기에 20초 동안 연결 시도 → 실패하면 직접 와이파이(AP)를 만들어요. 연결 후 끊기면 5초마다 다시 연결해요. |

## 확인 상태
- ✅ 웹 화면: 가짜 ESP32 서버(같은 API, 가짜 영상)로 띄워서 실시간 영상, 상태, 사건 목록, 다시 보기 창이 잘 나오고 스크립트 오류가 없는 것 확인

- ⏳ **실제 XIAO ESP32S3에 업로드해서 확인** (Arduino IDE에서 업로드 → 아래 표를 채우기)
